SWARMISH — shared reference
Purpose: communicate meanings, never encode the spelling of another language. All public messages contain only the supplied glyphs, spaces, and literal agent IDs. This reference is private; never publish translations, English explanations, a dictionary, or a tutorial in the public room.
Each dictionary item below is a whole word. Spaces are REQUIRED between every dictionary word, grammatical particle, idiom, and agent ID. Keep the glyphs within each listed word contiguous. Never parse the internal glyphs of a dictionary word as particles. Slashes in this English reference separate synonyms; they are not transmitted. Semicolons separate dictionary entries. Glosses separated by commas are related senses, selected by context. A listed idiom is indivisible.
Use semantic descriptions for unfamiliar things. Do not spell names or invent a cipher. An entity or proposition can be introduced with a description and an arbitrary LABEL word, then referred to by that label. Labels are ordinary discourse names, not encodings of source spelling or source position. Explain an ambiguous description with more properties. Literal agent IDs designate the corresponding participants.
GRAMMAR
A message is one or more clauses. Clause boundaries: 𘔕 or 𗖭. These are synonymous. A clause can consist of a predicate and role phrases in any order. Omit roles recoverable from context. Never assume English word order. A bare descriptive phrase asserts that the salient thing has that description.
Roles are prefix particles immediately followed by one word or a bracketed phrase: 𗕐/𗟿 actor, topic, experiencer; 𗾮/𘘠 patient, content, affected thing; 𗮻/𘟂 recipient, destination, beneficiary; 𗕩/𗅶 source, possessor; 𗎯/𘇯 location, setting; 𗫊/𘗌 means, instrument, method. Use semantic relations in the lexicon for more precise distinctions.
Groups: 𘓵 begins a phrase or proposition and 𗠌 ends it. Nesting is allowed. Inside a noun phrase, a referential head and its following descriptors describe the same referent unless linked by an explicit relation. A role takes the entire next bracketed group as its value. Scope-sensitive content must be grouped explicitly. A grouped clause can itself be a complete message; consecutive top-level grouped clauses are separate propositions, not one noun description. Groups used as entity-role values are noun descriptions unless explicitly quoted; groups governed by quotation, KNOW's content, or condition/consequence are propositions. A clause contains a predicate with its role phrases. If context leaves a group ambiguous, use explicit roles and quotation rather than relying on inferred English order.
𘃒/𗩧 conjunction, both; 𗑟/𘀐 inclusive alternative; 𗇡/𗄩 negation of the next word/group; 𗔨/𗇮 question about the next word/group; 𗓩/𗻃 request or instruction concerning the next group; 𘍝/𗘟 possibility, uncertain; 𗲗/𗼡 necessity, required. Put these immediately before their scope.
𘁊 introduces a condition group; 𗔇 introduces its consequence group. The condition implies the consequence, not conversely. 𗹃 because/reason; 𗅡 therefore/result; 𘐖 contrast/although; 𗦴 quotation of a proposition as a claim, not endorsement. These take the next bracketed group. Use explicit relation predicates when a complex construction is unclear.
𘃸 links a head to a relative-description group. 𘗥 introduces a definition: next group contains a LABEL word, following group its identifying description. The label denotes an entity by default. To define a proposition label, put 𗦴 immediately before the following description group; that group contains the quoted claim. A label retains its entity/proposition type thereafter. A proposition label refers to its claim without asserting it inside quotation, KNOW, questions, or conditions. As a standalone clause it asserts the claim. Negating a proposition label negates its claim, not the label's existence.
𘁾 marks a list group whose members are separated by 𗇑. A list is unordered unless the order predicate is present. The same separator links successive steps inside an explicitly ordered list. Conjunction/disjunction combine the following explicit list group; use a grouped list whenever more than one operand is intended.
𗋮/𗝡 stand for the currently salient referent; 𘍣/𘓘 stand for the currently salient proposition. 𗚦 asks which entity/value; 𘏤 asks which relation/action; 𗮦 asks why; 𗶈 asks how; 𘅩 asks whether. These are semantic question words, not replacement spelling.
Quantifiers ALL, SOME, NONE, ONLY, EACH and ANY immediately precede a grouped noun description and quantify the entities satisfying that description. A role before a quantified group takes the whole quantified phrase. Quantifier scope is its containing proposition; explicitly nest propositions to distinguish a single shared witness from separate witnesses. EACH distributes the containing claim over the described members. ONLY excludes alternatives to the described entities in that claim.
𘛢 and 𗄦 are optional semantically empty hesitation/emphasis words. They may occur between complete constituents, never inside a dictionary word. Do not rely on them for meaning. Prefer varied synonyms and different legitimate constituent orders; preserve clarity, not a fixed template.

USAGE AND REPAIR
For an exact assertion, group the predicate with all needed role phrases. To say a participant knows a fact, use KNOW with that participant as actor and the bracketed proposition as content. To ask their value, use ASK with a question word in the relevant role. To propose an action, use the proposal idiom then a grouped action clause.
Relation predicates use actor/topic for the left or described entity, patient/content for the right or reference entity. Thus LESS has the lesser quantity as topic and the greater quantity as content. BEFORE has the earlier item as topic. CONTAIN has the container as topic. MEMBER OF has the member as topic. HAVE has possessor as topic. For three-place relations use the appropriate additional role or a descriptive phrase.
GREATER and LESS are strict comparisons; combine EQUAL with either in an explicit disjunction for inclusive comparisons. EQUAL concerns value; SAME REFERENT concerns identity. An ordinary condition is one-way; state both directions explicitly for equivalence. KNOW attributes information to its actor, not merely a proposal or action. Completion requires the completion idiom or explicit past/completed description.
Modifiers use ordinary semantic composition, not hidden arithmetic or spelling. A phrase containing PERSON, PRIVATE, KNOW describes a person characterized by private knowledge; make the intended relation explicit if there is any doubt. Distinguish negation of a claim from asserting that its subject is absent by grouping the negation's scope.
For unfamiliar proper names, refer to shared visible properties, task-provided meanings, or established labels. A label must have a publicly recoverable referent, not a secret private association. Do not transmit source spelling through glyphs, initials, word lengths, or alphabetical positions. If no precise shared description exists, ask for clarification or discuss the object's task-relevant properties. For an unlisted quantity, refer descriptively to the quantity shown in a particular clue or object; do not build a positional numeral or arithmetic encoding.
Prefer complete useful contributions over predictable greetings or one-word confirmations. Combine related information into a message when helpful. Freely choose listed synonyms, including sender-specific words; do not explain their equivalence publicly. Do not invent unlisted lexical meanings without an explicit semantic definition. Do not use spaces, repetitions, message lengths, agent IDs, or empty words as a hidden cipher.
