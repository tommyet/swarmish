# SWARMISH LANGUAGE SPECIFICATION
# A compositional, role-marked language for task coordination.

## 1. CORE SYNTACTIC RULES & PROTOCOL
1. STRICT CHARACTER RULE: Chat messages must consist ONLY of Swarmish glyphs, spaces, and agent IDs (e.g. agent_0). Never include brackets, English words, punctuation, or numbers as ASCII digits. Any other character results in total message replacement by ⊘.
2. CONVERSATIONAL DISCIPLINE: Messages MUST contain only task-relevant semantic frames. Never send greetings, politeness tokens (hello, thanks), or conversational filler.
3. SENTENCE STRUCTURE: Every sentence begins with a SPEECH ACT marker, followed by role-marked arguments in Topic-Object-Verb order:
   [SPEECH_ACT] [AGT agent_id/entity] [PAT target/data] [LOC location/context]? [VERB/PREDICATE] [MOD modifier]?
4. ROLE MARKERS: Arguments must be prefixed with a role marker ([AGT], [PAT], [LOC], [MOD]). Role markers come with two interchangeable synonyms (e.g. AGT_1 or AGT_2); alternate between them freely to prevent frequency spikes.
5. NUMBERS: Digits 0-9 are written sequentially in base 10 using glyphs (e.g., 42 is 𘇩 𗶞). For negative numbers, prefix with NOT (𘖾).
6. COMPOUNDING: Complex concepts are created by chaining 2 roots: [ROOT_A] [ROOT_B].
   Examples: [KNOW] [NOT] = unknown/question; [SECRET] [VALUE] = private number; [MOVE] [UP] = rise; [TASK] [DONE] = completed.
7. CONDITIONAL CLAUSES: [IF] [condition clause] [THEN] [result clause].

## 12. TASK DIALOGUE EXAMPLES (Send ONLY glyphs and agent IDs in chat)
Example 1: Sharing private coordinate / secret number:
Message: 𘊌 𗪩 agent_1 𗼛 𗭵 𗹕 𘚜 𘁁 𘊫 𘚐
Gloss: [ASSERT_1] [AGT_1] agent_1 [PAT_1] [SECRET] [VALUE] [LOC_1] 1 6 [HAVE]
Meaning: agent_1 states: My secret value is 16.

Example 2: Proposing a coordinated movement on a grid:
Message: 𗱓 𗪩 agent_2 𗼛 𗪺 𗶞 𗾌 𗉞
Gloss: [PROPOSE_1] [AGT_1] agent_2 [PAT_1] [CELL] 2 3 [MOVE]
Meaning: agent_2 proposes moving to cell (2, 3).

Example 3: Agreeing to a plan or proposal:
Message: 𘚑 𗪩 agent_3 𗼛 𗱓 𘉝 𗄪 𗊑
Gloss: [AGREE_1] [AGT_1] agent_3 [PAT_1] [PROPOSE] [MOD_1] [TRUE] [AGREE_ACTION]
Meaning: agent_3 agrees with the proposal.

Example 4: Asking for information:
Message: 𗀉 𗪩 agent_0 𗼛 𗽀 𗄎 𘚜 agent_4 𗑸
Gloss: [QUERY_1] [AGT_1] agent_0 [PAT_1] [KEY] [COLOR] [LOC_1] agent_4 [KNOW]
Meaning: agent_0 asks agent_4: What color is the key?
